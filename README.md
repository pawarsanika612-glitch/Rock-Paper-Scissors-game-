# 🎮 Rock Paper Scissors Game

A simple, fun, and interactive **Rock Paper Scissors** web game where the player competes against the computer.

The game provides a clean modern interface, keeps track of the player's and computer's scores, and determines the winner of each round.

## ✨ Features

- 🪨 Rock, 📄 Paper, ✂️ Scissors choices
- 🤖 Computer opponent
- 🏆 Automatic winner detection
- 📊 Player and computer score tracking
- 🔄 Round-by-round gameplay
- 🎯 First-to-5 winning system
- 🏁 Match completion message
- 🔁 Reset Game option
- 📱 Responsive and mobile-friendly design
- 🎨 Modern dark-themed user interface

## 🎮 How to Play

1. Open the game.
2. Choose one of the three options:
   - 🪨 Rock
   - 📄 Paper
   - ✂️ Scissors
3. The computer automatically selects a move.
4. The winner of the round is displayed.
5. The scores are updated automatically.
6. The first player to reach **5 points** wins the match.
7. Click **Reset Game** to start a new match.

## 🧠 Game Rules

| Player Move | Beats |
|-------------|-------|
| 🪨 Rock | ✂️ Scissors |
| 📄 Paper | 🪨 Rock |
| ✂️ Scissors | 📄 Paper |

If both the player and computer select the same move, the round is a **Draw**.

## 🖥️ Interface

The game includes:

- Player's selected move
- Computer's selected move
- Match result
